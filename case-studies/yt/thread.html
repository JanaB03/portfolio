@janabridi Research 3 days ago (edited)

Save isn't really save.

I noticed I was hoarding "saved" posts I'd never look at again. The save button feels like remembering, but it's really just deferring. The product premise: let people thread a note onto the thing that triggered the save, so the why is captured at the same moment as the what.

No re-finding. No "wait which post was that." Just thoughts tied to the thing that sparked them.

02
@janabridi Design 3 days ago

The note shouldn't break the scroll.

The hardest design choice was where the note lives. A modal kills the scroll. A separate app means context-switching. So I designed it as a slim overlay that slides in over whatever you're watching — one tap, one field, dismiss to keep scrolling.

Type matters. The post was the trigger; the note has to feel secondary in hierarchy but fast in input.

03
@janabridi Build 3 days ago

Designed by hand. Built by AI.

Every line of code came out of an AI tool. My job was the taste — the flow, the feel, what stays, what gets cut. The AI's job was the typing.

  • Claude Code — build engine. Components, state, the overlay logic.
  • Figma Make — first-pass UI. Faster than wireframing from scratch.
  • Cursor — inline edits. File-by-file polish.
  • ChatGPT — prompt sharpening. Clearer asks in, better code out.

Loop: sketch idea → ChatGPT prompt → Figma Make UI → Claude Code build → Cursor polish.
