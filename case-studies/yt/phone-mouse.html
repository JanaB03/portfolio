Phone-as-Mouse

Turning an iPhone into a desktop mouse using camera optical flow. Point the phone at any surface — your cursor follows.

RoleDesigner · AI-assisted builder
Year2026 · in progress
StackSwiftUI · Python (Windows) · Claude Code · Cursor

↑ Optical flow → cursor pad → gestures → custom cursor

01 The idea

Your phone is the best input device you already own.

You carry it everywhere. It has a camera with computer-vision tracking baked in. Why are we still buying separate pieces of plastic to move a cursor? The project started as a "what if" — by hour two of prototyping it was clearly possible.

02 Features

Four features in the prototype.

01

Optical flow tracking

Point the rear camera at any textured surface — the cursor follows. Core feature, the whole reason the rest exists.

02

Cursor pad — touch mode

For when the camera approach isn't practical. The phone screen becomes a trackpad in your pocket.

03

Trackpad gestures

Two-finger scroll, tap-to-click, drag. The small things that make a trackpad feel like a trackpad.

04

Custom cursor

Pick a cursor that looks like you. If your input device is a screen, the cursor should match the vibe.

03 Build

iOS app, Windows companion, AI in the middle.

The iPhone runs a SwiftUI app that streams camera frames + touch events over the local network. A small Python service on Windows reads the stream and translates it into mouse movement. Both halves were scaffolded and iterated with Claude Code and Cursor — most of the typing was AI, most of the "what to build next" was me.

SwiftUI Vision framework Python · Windows Claude Code Cursor
04 Reflection

Small device, big posture experiment.

The interesting question isn't "can a phone be a mouse" — it's "what does a desk feel like when the mouse is just whatever you happen to be holding." Working through this prototype is teaching me what people actually want from a pointing device, and what gets in the way.
