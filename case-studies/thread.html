Case Study — Full AI Build

Thread

A note-taking layer for your feed. Thread sits on top of Instagram and TikTok so the things you save while scrolling — recipes, hot-takes, outfit ideas, that one bookshelf — actually become notes you can come back to, instead of getting buried in the "saved" tab.

Role Designer · AI-assisted builder
Stack Claude Code · Figma Make · Cursor · ChatGPT
Timeframe 2026 · weekend prototype

↑ Quick walkthrough — taking notes without leaving the scroll.

01 The idea

Save isn't really save.

I noticed I was hoarding "saved" posts I'd never look at again. The save button feels like remembering, but it's really just deferring. Thread reframes the moment: a one-tap note slides in over the video, you jot the why — the recipe, the quote, the idea it sparked — and it lands in a real note you actually own.

No re-finding. No "wait which post was that." Just thoughts threaded to the thing that triggered them.

02 How I built it

Designed by hand, built by AI.

Every line of code in Thread was generated through AI tools. My job was the taste — the flow, the feel, what stays, what gets cut. The AI's job was the typing. Here's the stack:

C
Build engine Claude Code Drove the actual implementation — components, state, the overlay logic. Where the bulk of the app got made.
F
UI generation Figma Make First-pass screens and visual layout. Faster than wireframing from scratch.
↳
Inline edits Cursor Quick file-by-file changes and small refactors when I wanted to nudge a detail without a full rebuild.
G
Prompting partner ChatGPT Used to sharpen the prompts I fed the build tools — clearer asks in, better code out.
Sketch idea → ChatGPT: prompt → Figma Make: UI → Claude Code: build → Cursor: polish
03 What I took away

The designer becomes the director.

Building Thread without writing code myself changed how I think about my own role. The bottleneck wasn't the typing — it was knowing what to make and what to leave out. AI tools collapse the gap between "I want it to feel like this" and "here it is, running." The taste is still mine. The hands are faster.
